# nnpas_centiles
Processing and analysis code for "Eckmann, H.R., Razieh, C., Chastin, S., Sherar, L. B., Steene-Johannessen, J., Hansen, B. H., Rowlands, A. V. (2026). Age-referenced centiles of physical activity volume and intensity in the Norwegian National Physical Activity Survey." Submitted for publication.

Note that the addMIMS function is updated compared to previous papers due to idle sleep mode being on for the ActiGraphs used in NNPAS.
